# Интеграция платёжной системы Prodamus

Покупатель создаёт заказ и переходит по подписанной ссылке на защищённую платёжную форму Prodamus. После оплаты Prodamus уведомляет сервер, который обновляет статус заказа и отправляет уведомление администраторам в Telegram.

## Переменные окружения

Задайте переменные в Production:

```env
PRODAMUS_URL=https://вашшоп.payform.ru
PRODAMUS_SECRET_KEY=секретный_ключ_из_кабинета
PUBLIC_URL=https://www.hustlify.site
```

`PRODAMUS_URL` должен содержать только домен платёжной формы, без пути и параметров. Скопируйте секретный ключ без пробелов. `PRODAMUS_SYS` задаётся только если Prodamus выдал вам это значение.

## Кабинет Prodamus и деплой

В поле «Уведомления» укажите `https://www.hustlify.site/api/webhooks/prodamus`. `PUBLIC_URL` используется для адресов возврата после оплаты и URL уведомления.

На Vercel проверьте, что `PRODAMUS_URL` и `PRODAMUS_SECRET_KEY` указаны для Production. После изменения переменных выполните Redeploy, иначе функция продолжит использовать старое окружение.

## Серверные маршруты

- Создание платежа: `POST /api/payments/prodamus/create`
- Алиасы для уже открытых вкладок: `POST /api/payments/create` и `POST /api/payments/rollypay/create`
- Уведомления об оплате: `POST /api/webhooks/prodamus`

Создание платежа принимает JSON с идентификатором заказа, например `{ "orderId": "hustlify_1727..." }`. Подпись вебхука проверяется по секретному ключу; при успешной оплате статус заказа становится `paid`.
