# Рулетка Hustlify

Блок рулетки размещён на главной странице после ленты новостей.

- `public/index.html` — HTML-разметка и подключение скрипта/стилей.
- `public/css/roulette.css` — адаптивная вёрстка по макету Figma.
- `public/js/roulette.js` — два быстрых цикла на скоростях 3× и 2×, затем плавное замедление финального цикла; показ/копирование промокода и таймер 24 часа.
- `public/videos/roulette-wheel.webm` — исходный ролик.
- `public/videos/roulette-wheel-sequence.webm` — готовая последовательность: два бесшовных активных фрагмента по 2 секунды, затем исходный ролик для финальной остановки. Видео интерполировано до 48 кадров/с, чтобы замедление не превращалось в рывки.
- `build-roulette-sequence.sh` — пересборка последовательности из исходного ролика (нужен FFmpeg с `libvpx-vp9`).
- `public/images/roulette-video-poster.png` — прозрачный постер первого кадра до загрузки видео.
- `public/images/roulette-video-mask.png` — растровая маска контура для браузеров, которые не показывают альфа-канал VP9/WebM.
- `public/images/roulette-still-*.png` — кадры соответствующих скидок для режима уменьшения анимации и резервного отображения.
- `index.js` — генерация промокодов и серверная вероятность скидок.

API `POST /api/promo/generate` остаётся источником результата и сохраняет промокод на сервере. Первые два активных цикла склеены заранее в последовательность до естественного замедления исходного видео, поэтому на переходах колесо не замирает и не перезапускает ролик с заметным скачком. Скорости циклов — 3×, 2× и 1×; переходы скорости сглажены. Финальная остановка замедляется на протяжении 1,35 секунды исходного видео, а минимальная скорость ограничена 0,5×, чтобы сохранить плавность. Для скидок 5%, 10%, 15%, 25% и 30% заданы свои временные отметки; если для скидки есть несколько подходящих кадров, один выбирается случайно. Частота вращения ограничена разом в 24 часа; клиентский таймер дополняет серверный контроль. Настройка `roulette_hidden` в админ-панели по-прежнему скрывает блок и ссылки на него.

Распределение скидок: 5% — 38%; 10% — 30,4%; 15% — 19%; 25% — 7,6%; 30% — 5%.
