# Рулетка Hustlify

Блок рулетки размещён на главной странице после ленты новостей.

- `public/index.html` — HTML-разметка и подключение скрипта/стилей.
- `public/css/roulette.css` — адаптивная вёрстка по макету Figma.
- `public/js/roulette.js` — три цикла видео на скоростях 3×, 2× и 1×, затем плавное замедление к случайной временной отметке нужного сектора; показ/копирование промокода и таймер 24 часа.
- `public/videos/roulette-wheel.webm` — приложенное видео с удалённым фоном и прозрачностью; исходный ролик не переводится в вектор.
- `public/images/roulette-video-poster.png` — прозрачный постер первого кадра до загрузки видео.
- `public/images/roulette-video-mask.png` — растровая маска контура для браузеров, которые не показывают альфа-канал VP9/WebM.
- `public/images/roulette-still-*.png` — кадры соответствующих скидок для режима уменьшения анимации и резервного отображения.
- `index.js` — генерация промокодов и серверная вероятность скидок.

API `POST /api/promo/generate` остаётся источником результата и сохраняет промокод на сервере. Видео зациклено по полному исходному ролику: первый цикл идёт на скорости 3×, второй — 2×, третий — 1× с плавным замедлением к одной из временных отметок, соответствующих скидке от API. Для скидок 5%, 10%, 15%, 25% и 30% заданы свои точки остановки; если для скидки есть несколько подходящих кадров, один выбирается случайно. Частота вращения ограничена разом в 24 часа; клиентский таймер дополняет серверный контроль. Настройка `roulette_hidden` в админ-панели по-прежнему скрывает блок и ссылки на него.

Распределение скидок: 5% — 38%; 10% — 30,4%; 15% — 19%; 25% — 7,6%; 30% — 5%.
